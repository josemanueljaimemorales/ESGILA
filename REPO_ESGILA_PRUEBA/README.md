# REPO ESGILA — PRUEBA WHITE LABEL

Repositorio autónomo de prueba para un gimnasio cliente.

## Cambiar identidad
Editar solamente `cliente/config.js` y sustituir `cliente/logo.png`.

Los módulos están dentro de `modulos/` y ya no dependen de URLs de los repositorios AKC para abrirse desde el portal.

## Importante
La prueba conserva los archivos de datos/Excel de los módulos originales. El módulo de Fuerza y Prevención conserva su integración Firebase actual como referencia técnica; para una venta real debe asignarse una configuración Firebase independiente por gimnasio.
